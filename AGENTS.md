# UI instructions for EBD IADP

Before any UI change, read `DESIGN.md` in the project root.

Also inspect `css/system.css` and preserve the existing project fonts, assets and companion stylesheets. If `html/preview.html` exists, use it as a visual reference.

Prefer small, scoped CSS changes over rewriting application logic. Preserve Supabase, navigation, data rendering, authentication and accessibility behavior.
